# challenge-amigo-secreto
practicando con Alura

# Funcionalidades:
- Agregar nombres de amigos a una lista.
- Mostrar en pantalla los amigos registrados.
- sortear un amigo de forma aleatoria.
- limpiar el campo de texto después de cada registro.

# Tecnologías utilizadas:
- HTML5 
- CSS
- JavaScript

# Uso del proyecto:
- clona este repositorio o descarga los archivos.
- Abre el archivo `index.html` en tu navegador.
- Ingresa los nombres de tus amigos en el campo de texto y haz clic en **Añadir**.
- La lista de amigos se actualizará automáticamente.
- Cuando todos estén agregados, presiona el botón **Sortear amigo**.
- El sistema seleccionará un nombre aleatorio y lo mostrará en pantalla.

# Este proyecto fue creado con fines educativos para reforzar:  

- Uso de **funciones en JavaScript**.  
- Manejo de **arrays** (agregar y recorrer elementos).  
- Manipulación del **DOM** (crear y actualizar elementos HTML).  
- Aplicación de **Math.random()** y **Math.floor()** para generar resultados aleatorios.
